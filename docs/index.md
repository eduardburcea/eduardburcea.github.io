-   **Homelab: Cybersecurity Lab**

    A home lab designed to provide an isolated environment for hands-on cybersecurity practice. The goal is to simulate security incidents, test intentionally vulnerable machines, assess vulnerabilities across different operating systems and software versions, harden systems, and safely experiment with malware in a controlled environment. -   **RouterOS: Home Network Upgrade**

    <small>Coming soon</small>

    ---

    An upgrade of my home network, replacing my ISP-provided router with a MikroTik router. The project focuses on segmenting the network with VLANs to isolate untrusted devices (such as IoT devices) and separate the homelab environment from the internet and other devices on my LAN. The broader goals are to improve network performance, reliability, and security through better traffic management, access controls, and network design.

    **Technologies:** MikroTik RouterOS, VLANs, DNS, DHCP, firewall rules, and network segmentation.
